## 🎥 Що записати на відео (якщо потрібно)

### 1. Відкриття сайту (10 сек)
- Показати головну сторінку
- Показати кнопку чату в куті

### 2. Демо чату (30 сек)
- Клікнути на чат
- Написати "Привіт"
- Отримати відповідь
- Написати "Розкажи про Jett"
- Показати відповідь AI

### 3. Код (20 сек)
- Показати `aiService.ts` (OpenRouter інтеграція)
- Показати `ChatAssistant.tsx` (UI)
- Показати `.env.example` (конфігурація)

### 4. GitHub (10 сек)
- Показати репозиторій
- Показати коміти
- Показати README

### 5. Документація (10 сек)
- Показати файли документації
- Швидко прокрутити DOCUMENTATION.md

**Загальний час: ~1.5 хвилини**
