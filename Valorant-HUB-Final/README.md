# VALORANT HUB

Your ultimate VALORANT companion application.

## 🚀 Features

- **Interactive Maps** - Master all VALORANT maps with detailed callouts
- **Agent Guides** - Comprehensive guides for all agents
- **VCT Esports** - Follow professional tournaments and teams
- **Player Profile** - Track your stats and progress

## 🛠️ Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:5173`

## 📦 Build

To build for production:
```bash
npm run build
```

## 🎨 Tech Stack

- React 18
- TypeScript
- Vite
- Material-UI (MUI)
- React Router
