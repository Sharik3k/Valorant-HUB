# ⏱️ Rate Limits & Optimization

## 🚨 Проблема

Gemini API має дуже жорсткі обмеження на безкоштовному tier:
- **15 запитів на хвилину (RPM)**
- **1 мільйон токенів на день**
- **1500 запитів на день (RPD)**

Але на практиці ліміти можуть бути ще жорсткішими через:
- Спільне використання квоти між користувачами
- Регіональні обмеження
- Тимчасові обмеження API

## ✅ Наші рішення

### 1. **Client-Side Rate Limiting**
```typescript
// Мінімальний cooldown між запитами: 5 секунд
// При rate limit помилці: 60 секунд
```

**Переваги:**
- Запобігає надмірним запитам
- Покращує UX з таймером
- Економить квоту API

### 2. **Server-Side Rate Limiting**
```javascript
// Максимум 2 запити на хвилину на IP
const MAX_REQUESTS_PER_WINDOW = 2;
const RATE_LIMIT_WINDOW = 60000; // 60 секунд
```

**Переваги:**
- Захист від зловживань
- Справедливий розподіл квоти
- Запобігає DDoS

### 3. **Оптимізація токенів**
```javascript
// Короткий системний промпт
const systemPrompt = 'AI асистент VALORANT HUB. Відповідай коротко українською або англійською.';

// Обмеження відповіді
maxOutputTokens: 500
```

**Економія:**
- ~80% токенів на системному промпті
- Швидші відповіді
- Більше запитів на день

### 4. **UI Індикатори**
- ⏳ Таймер cooldown
- 🔴 Повідомлення про ліміт
- ℹ️ Інформація про квоту

## 📊 Моніторинг

### Як перевірити використання:
1. Перейдіть на [Google AI Studio](https://makersuite.google.com/)
2. Відкрийте "API Keys"
3. Перегляньте "Usage"

### Метрики для відстеження:
- Запити на хвилину (RPM)
- Токени на день
- Помилки 429 (Rate Limit)

## 🔧 Налаштування лімітів

### Змінити ліміти в коді:

**Frontend (ChatAssistant.tsx):**
```typescript
// Мінімальний cooldown (мілісекунди)
setCooldownUntil(Date.now() + 5000); // 5 секунд

// Cooldown після rate limit
setCooldownUntil(Date.now() + 60000); // 60 секунд
```

**Backend (api/chat.js):**
```javascript
// Максимум запитів
const MAX_REQUESTS_PER_WINDOW = 2;

// Вікно часу (мілісекунди)
const RATE_LIMIT_WINDOW = 60000; // 60 секунд
```

## 💡 Поради

### Для розробки:
1. Використовуйте мінімальні cooldown (5-10 секунд)
2. Тестуйте з реальними лімітами
3. Логуйте всі rate limit помилки

### Для продакшну:
1. Збільшіть cooldown (10-15 секунд)
2. Додайте кешування відповідей
3. Розгляньте платний tier для кращого UX

### Для користувачів:
1. Пишіть конкретні запитання
2. Чекайте між запитами
3. Використовуйте пошук перед запитом до AI
