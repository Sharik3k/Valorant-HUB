# Vector & Hybrid Search Setup

## Огляд

Цей бекенд тепер підтримує векторний та гібридний пошук для гравців та агентів Valorant, використовуючи:
- **Gemini API** для створення ембедингів (векторних представлень)
- **OpenRouter/OpenAI** для AI чат-асистента
- **In-memory векторне сховище** для швидкого пошуку

## Налаштування

### 1. Отримайте Gemini API ключ

1. Перейдіть на [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Створіть новий API ключ
3. Скопіюйте ключ

### 2. Налаштуйте змінні середовища

Створіть файл `.env` в директорії `backend`:

```bash
# Для AI чату (OpenRouter або OpenAI)
OPENROUTER_API_KEY=sk-or-v1-your-key-here
# АБО
OPENAI_API_KEY=sk-your-openai-key-here

# Для векторного пошуку (Gemini)
GEMINI_API_KEY=your-gemini-api-key-here

PORT=3001
```

### 3. Встановіть залежності

```bash
npm install
```

### 4. Запустіть сервер

```bash
npm run dev
```

При старті сервер автоматично:
- Завантажить дані про гравців з JSON файлів
- Створить вектори для агентів та перших 100 гравців
- Підготує систему для пошуку

## API Ендпоінти

### 1. Пошук агентів (Vector Search)

```bash
POST /api/search/agents
Content-Type: application/json

{
  "query": "aggressive duelist with mobility",
  "topK": 5
}
```

**Відповідь:**
```json
[
  {
    "name": "Jett",
    "score": 0.87
  },
  {
    "name": "Raze",
    "score": 0.82
  }
]
```

### 2. Пошук гравців (Vector Search)

```bash
POST /api/search/players
Content-Type: application/json

{
  "query": "best jett player with high headshot percentage",
  "topK": 10
}
```

**Відповідь:**
```json
[
  {
    "player": {
      "playerName": "zekken",
      "team": "SEN",
      "rating": "1.13",
      "region": "Americas",
      "playerStatistics": {
        "average_combat_score": "255.3",
        "kill_deaths": "1.19",
        "headshot_percentage": "24%"
      },
      "agent": ["raze", "jett", "neon"]
    },
    "score": 0.91
  }
]
```

### 3. Гібридний пошук (Hybrid Search)

Комбінує векторний пошук з keyword-based пошуком для кращих результатів.

```bash
POST /api/search/hybrid
Content-Type: application/json

{
  "query": "sentinels jett",
  "topK": 10
}
```

**Відповідь:**
```json
[
  {
    "player": {
      "playerName": "TenZ",
      "team": "SEN",
      "rating": "1.15",
      "agent": ["jett", "chamber"]
    },
    "score": 1.42,
    "matchType": "hybrid"
  }
]
```

**Match Types:**
- `vector` - знайдено тільки векторним пошуком
- `keyword` - знайдено тільки за ключовими словами
- `hybrid` - знайдено обома методами (найкращі результати)

## Як це працює

### Векторний пошук

1. При старті сервера кожен гравець/агент перетворюється на текстовий опис
2. Gemini API створює векторне представлення (embedding) цього опису
3. При пошуку запит також перетворюється на вектор
4. Обчислюється косинусна подібність між запитом та всіма збереженими векторами
5. Повертаються найбільш подібні результати

### Гібридний пошук

1. Виконується векторний пошук (70% ваги)
2. Виконується keyword пошук за ключовими словами
3. Результати комбінуються з бонусами за:
   - Високу векторну подібність
   - Позицію в рейтингу
   - Збіг в обох типах пошуку
4. Повертаються топ результати

## Переваги

- **Семантичний пошук**: розуміє значення запиту, а не тільки ключові слова
- **Гнучкість**: можна шукати природною мовою ("найкращий гравець на Jett")
- **Точність**: гібридний підхід покращує релевантність результатів
- **Швидкість**: in-memory зберігання забезпечує миттєвий пошук

## Обмеження

- Зараз обробляється тільки перші 100 гравців (щоб не перевантажувати API)
- Вектори зберігаються в пам'яті (при рестарті сервера потрібна реініціалізація)
- Gemini API має ліміти на кількість запитів
