## 🎯 Про проект

Це повнофункціональний сайт про VALORANT з інтегрованим **AI чат-асистентом**, який допомагає гравцям з питаннями про гру.

### Виконані вимоги
✅ Репозиторій на GitHub  
✅ Підключення до AI API (OpenRouter)  
✅ Готовий до деплою на Vercel

## ⚡ Швидкий старт

### Крок 1: API ключ (1 хв)
```bash
# Отримайте безкоштовний ключ
https://openrouter.ai/keys
```

### Крок 2: Налаштування (2 хв)
```bash
# Клонуйте та встановіть
git clone https://github.com/Sharik3k/Valorant-HUB.git
cd Valorant-HUB-Final
npm install

# Створіть .env
cp .env.example .env
# Додайте ваш ключ у .env
```

### Крок 3: Запуск (10 сек)
```bash
npm run dev
# Відкрийте http://localhost:5173
# Клікніть на 💬 в куті екрану
```
