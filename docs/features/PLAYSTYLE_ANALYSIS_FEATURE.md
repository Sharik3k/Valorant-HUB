# 🎯 Аналіз Стилю Гри - Нова Функція

## Огляд

Додано нову функцію **Аналізу Стилю Гри**, яка допомагає гравцям знайти найкращих агентів VALORANT на основі їх особистого стилю гри.

## ✨ Що Нового

### 1. **Вкладки в AI Chat**
- 💬 **AI Чат** - звичайний чат з AI
- 🎯 **Аналіз Стилю Гри** - нова вкладка для рекомендацій агентів

### 2. **Інтерактивний Квіз (5 Питань)**

Гравець відповідає на питання про свій стиль гри:

1. **Агресія**
   - 🔥 Агресивно - люблю першим входити, брати дуелі
   - ⚖️ Збалансовано - залежить від ситуації  
   - 🛡️ Пасивно - граю від оборони, підтримую команду

2. **Командна гра**
   - 👥 Граю з командою, координуюсь, допомагаю
   - 🤝 Інколи з командою, інколи сам
   - ⭐ Граю сам, роблю фланки, carry

3. **Фокус**
   - 🎯 На стрільбі та дуелях
   - ⚖️ На всьому порівну
   - 🛠️ На використанні здібностей та стратегії

4. **Досвід**
   - 🌱 Початківець (тільки почав грати)
   - 📈 Середній (граю кілька місяців)
   - 🏆 Досвідчений (граю довго, знаю механіки)

5. **Улюблена роль**
   - ⚔️ Duelist - агресія, entry fragging
   - 💨 Controller - смоки, контроль карти
   - 🔍 Initiator - інформація, підтримка атаки
   - 🛡️ Sentinel - захист, утримання позицій
   - 🎲 Будь-яка - граю на всіх ролях

### 3. **ТОП-5 Рекомендованих Агентів**

На основі відповідей система рекомендує 5 найкращих агентів з поясненням:

- **Рейтинг** (#1, #2, #3...)
- **Роль агента** (Duelist, Controller, Initiator, Sentinel)
- **Складність** (Easy, Medium, Hard)
- **Опис агента**
- **Чому підходить** - конкретні причини відповідності стилю
- **Поради** - як грати цим агентом

## 🔍 Як Працює Алгоритм

### Система Оцінювання

Кожен агент має 4 параметри (1-10):
- **Aggression** - рівень агресії
- **Teamplay** - орієнтація на команду
- **Utility** - залежність від здібностей
- **Versatility** - універсальність

### Підрахунок Балів

```
Загальна оцінка = 
  Aggression Match × 30% +
  Teamplay Match × 30% +
  Utility Match × 25% +
  Versatility × 15%
```

### Фільтрація

- За складністю (відповідно до досвіду)
- За роллю (якщо вказано перевагу)

### Сортування

Агенти сортуються за фінальною оцінкою, топ-5 показуються користувачу.

## 🎮 Як Використовувати

### 1. Відкрити AI Chat
- На головній сторінці натисніть **"AI Chat Assistant"**

### 2. Перейти до Аналізу
- Натисніть вкладку **"🎯 Аналіз Стилю Гри"**

### 3. Почати Квіз
- Натисніть кнопку **"Почати Аналіз"**

### 4. Відповісти на 5 Питань
- Оберіть відповіді, які найбільше відповідають вашому стилю
- Прогрес показується вгорі
- Можна повертатись назад

### 5. Переглянути Результати
- Система покаже ТОП-5 агентів
- Кожен з детальним описом та порадами
- Результати зберігаються локально

### 6. Пройти Знову (Опціонально)
- Кнопка **"Пройти знову"** для нового аналізу
- Або **"Скинути результати"** для очищення

## 🎓 Технічні Деталі

### TypeScript Types
```typescript
interface PlaystyleAnswers {
  aggression: 'passive' | 'balanced' | 'aggressive';
  teamplay: 'solo' | 'balanced' | 'team';
  focus: 'aim' | 'balanced' | 'utility';
  experience: 'beginner' | 'intermediate' | 'advanced';
  preferredRole?: 'Duelist' | 'Controller' | 'Initiator' | 'Sentinel' | 'any';
}

interface AgentPlaystyle {
  name: string;
  role: 'Duelist' | 'Controller' | 'Initiator' | 'Sentinel';
  difficulty: 'Easy' | 'Medium' | 'Hard';
  playstyle: {
    aggression: number;
    teamplay: number;
    utility: number;
    versatility: number;
  };
  bestFor: string[];
  description: string;
  tips: string[];
}
```
