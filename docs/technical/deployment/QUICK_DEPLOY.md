# ⚡ Швидкий деплой

## 🚀 Vercel (2 хвилини)

1. Перейдіть на [vercel.com](https://vercel.com)
2. Увійдіть через GitHub
3. Натисніть "Add New Project"
4. Виберіть репозиторій `Valorant-HUB`
5. Натисніть "Deploy"

**Готово!** 🎉

---

## 📱 Netlify (2 хвилини)

1. Перейдіть на [netlify.com](https://netlify.com)
2. Увійдіть через GitHub
3. "Add new site" → "Import from Git"
4. Виберіть репозиторій
5. Натисніть "Deploy site"

**Готово!** 🎉

---

## 🔑 Змінні середовища (опціонально)

Якщо у вас є `.env` файл, додайте змінні в налаштуваннях хостингу:

**Vercel:** Settings → Environment Variables  
**Netlify:** Site settings → Environment variables
