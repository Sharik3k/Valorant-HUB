## Що таке OpenRouter

**OpenRouter** - це платформа, яка надає уніфікований доступ до різних AI моделей через один API. Це дозволяє використовувати моделі від OpenAI, Anthropic, Google, Meta та інших провайдерів через єдиний інтерфейс.

### Переваги OpenRouter:

- ✅ **Єдиний API** для різних AI моделей
- ✅ **Безкоштовні моделі** (наприклад, Llama 3.1 8B)
- ✅ **Гнучке ціноутворення** - платите тільки за використання
- ✅ **Автоматичний fallback** між моделями
- ✅ **Детальна статистика** використання

## Налаштування OpenRouter API

### Крок 1: Реєстрація

1. Перейдіть на [openrouter.ai](https://openrouter.ai)
2. Натисніть **"Sign Up"** у верхньому правому куті
3. Зареєструйтесь через:
   - GitHub
   - Google
   - Email

### Крок 2: Отримання API ключа

1. Після входу перейдіть в розділ **"API Keys"** (або [openrouter.ai/keys](https://openrouter.ai/keys))
2. Натисніть **"Create Key"**
3. Введіть назву ключа (наприклад, "Valorant HUB")
4. Встановіть ліміти (опціонально):
   - **Rate limit** - кількість запитів за хвилину
   - **Monthly budget** - місячний бюджет в доларах
5. Натисніть **"Create"**
6. **ВАЖЛИВО**: Скопіюйте ключ одразу, він більше не буде показаний!

### Крок 3: Поповнення балансу (опціонально)

**Для безкоштовних моделей** (як Llama 3.1 8B Free) поповнення не потрібне!

Якщо хочете використовувати платні моделі:
1. Перейдіть в розділ **"Credits"**
2. Натисніть **"Add credits"**
3. Оберіть суму (мінімум $5)
4. Введіть платіжні дані
5. Підтвердіть оплату

## Інтеграція в проект

### Крок 1: Встановлення залежностей

Проект вже використовує необхідні бібліотеки:
- React

- React Router

Ніяких додаткових npm пакетів встановлювати не потрібно!

1. Запустіть проект:
   ```bash

2. Відкрийте додаток в браузері (зазвичай `http://localhost:5173`)

5. Натисніть **"Go to Settings"** або клацніть іконку ⚙️ у верхньому правому куті

6. Вставте свій OpenRouter API ключ

7. Оберіть модель AI (рекомендуємо почати з **Llama 3.1 8B Free**)

8. Натисніть **"Save"**

9. Готово! Можна почати чат 🎉

## Використання

### Базове використання

1. **Відкрийте чат**: Натисніть на "AI Chat Assistant" на головній сторінці
2. **Напишіть повідомлення**: Введіть текст у поле внизу
3. **Відправте**: Натисніть кнопку Send (✉️) або Enter
4. **Отримайте відповідь**: AI відповість через кілька секунд

```

## 🔒 Безпека

### Збереження API ключа:

- ✅ API ключ зберігається **локально** в браузері (`localStorage`)
- ✅ Ключ **ніколи не відправляється** на сервер проекту
- ✅ Ключ використовується **тільки** для прямих запитів до OpenRouter
- ⚠️ **НЕ ДОДАВАЙТЕ** API ключ в код або Git!

### Рекомендації:

1. **Не діліться** своїм API ключем з іншими
2. **Встановіть ліміти** на ключі (rate limit, budget)
3. **Регулярно оновлюйте** ключі
4. **Використовуйте змінні оточення** для production збірки

## 🐛 Вирішення проблем

### Помилка: "Please configure your OpenRouter API key"

**Рішення**: 
1. Відкрийте Settings (⚙️)
2. Введіть валідний API ключ
3. Натисніть Save

### Помилка: "OpenRouter API Error: 401"

**Причина**: Невірний або прострочений API ключ

**Рішення**:
1. Перевірте правильність ключа
2. Створіть новий ключ на openrouter.ai
3. Оновіть ключ в Settings

### Помилка: "OpenRouter API Error: 402"

**Причина**: Недостатньо кредитів (для платних моделей)

**Рішення**:
1. Поповніть баланс на openrouter.ai
2. Або змініть модель на безкоштовну (Llama 3.1 8B Free)

### Помилка: "Failed to communicate with OpenRouter API"

**Причина**: Проблеми з інтернет-з'єднанням або CORS

**Рішення**:
1. Перевірте інтернет-з'єднання
2. Перевірте консоль браузера на помилки
3. Спробуйте оновити сторінку
