# 🔑 OpenRouter - Детальна інструкція з реєстрації та налаштування

## Покрокова інструкція з скріншотами (текстовий опис)

---

## Крок 1: Реєстрація на OpenRouter

### 1.1 Відкрийте сайт
1. Перейдіть на **https://openrouter.ai**
2. У верхньому правому куті знайдіть кнопку **"Sign Up"**
3. Натисніть на неї

### 1.2 Оберіть спосіб реєстрації
У вас є 3 варіанти:

**Варіант A: Через GitHub (рекомендовано)**
- Натисніть кнопку "Sign up with GitHub"
- Авторизуйте додаток OpenRouter
- Готово! Ви автоматично увійдете в систему

**Варіант B: Через Google**
- Натисніть кнопку "Sign up with Google"
- Оберіть свій Google акаунт
- Підтвердіть доступ
- Готово!

**Варіант C: Через Email**
- Введіть свій email
- Створіть пароль (мінімум 8 символів)
- Підтвердіть email через лист
- Увійдіть в систему

## Крок 2: Створення API ключа

### 2.1 Перейдіть до розділу API Keys
Після входу в систему:

1. У лівому меню натисніть **"API Keys"**
   - АБО перейдіть за прямим посиланням: **https://openrouter.ai/keys**

2. Ви побачите сторінку з вашими API ключами
   - Якщо це перший раз, список буде пустий

### 2.2 Створіть новий ключ

1. Натисніть кнопку **"Create Key"** (або "+ New Key")

2. З'явиться форма створення ключа з полями:

   **Name (Назва ключа)**
   ```
   Приклад: "Valorant HUB Development"
   або: "My VALORANT App"
   ```
   💡 Порада: Використовуйте описову назву, щоб знати для чого цей ключ

   **Rate Limit (Ліміт запитів) - ОПЦІОНАЛЬНО**
   ```
   Приклад: 60 requests per minute
   ```
   💡 Порада: Для початку можна залишити пустим або поставити 60/minute

   **Monthly Budget (Місячний бюджет) - ОПЦІОНАЛЬНО**
   ```
   Приклад: $5.00 або $10.00
   ```
   💡 Порада: Для безкоштовних моделей бюджет не потрібен!

3. Натисніть кнопку **"Create"**

### 2.3 Збережіть API ключ

⚠️ **КРИТИЧНО ВАЖЛИВО!**

1. Після створення з'явиться вікно з вашим API ключем
2. Ключ виглядає приблизно так:
   ```
   sk-or-v1-1234567890abcdefghijklmnopqrstuvwxyz1234567890abcdefghijklmnop
   ```

3. **СКОПІЮЙТЕ ЦЕЙ КЛЮЧ ОДРАЗУ!**
   - Натисніть кнопку **"Copy"** або виділіть та скопіюйте вручну
   - Ключ показується **тільки один раз**!
   - Якщо закриєте вікно - ключ не можна буде подивитись знову

4. Збережіть ключ у безпечному місці:
   - Вставте у текстовий файл
   - АБО відразу використайте у додатку
   - **НЕ ПУБЛІКУЙТЕ** ключ в публічних репозиторіях!

5. Натисніть **"Done"** або закрийте вікно

## Крок 3: Налаштування безпеки (рекомендовано)

### 3.1 Встановіть ліміти

Після створення ключа, ви можете встановити додаткові обмеження:

**Rate Limits (Ліміти частоти запитів)**
```
Рекомендовано для розробки: 60 requests/minute
Для production: 100-200 requests/minute
```

**Budget Limits (Бюджетні ліміти)**
```
Для безкоштовних моделей: $0 (не потрібно)
Для тестування платних: $5-10/month
Для production: $50-100/month
```

### 3.2 Налаштуйте повідомлення

Увімкніть сповіщення про:
- Досягнення 80% бюджету
- Помилки авторизації
- Підозрілу активність

## Крок 4: Поповнення балансу (тільки для платних моделей)

### 4.1 Коли потрібно поповнювати?

**НЕ ПОТРІБНО** якщо ви використовуєте:
- ✅ Llama 3.1 8B Free
- ✅ Gemini Flash 1.5 (обмежений безкоштовний)
- ✅ Інші моделі з позначкою "Free"

**ПОТРІБНО** якщо хочете використати:
- GPT-4, GPT-3.5 Turbo
- Claude 3 (Opus, Sonnet, Haiku)
- Gemini Pro (необмежений)

### 4.2 Як поповнити баланс

1. Перейдіть в розділ **"Credits"** або **"Billing"**

2. Натисніть **"Add Credits"**

3. Оберіть суму:
   ```
   Мінімум: $5.00
   Рекомендовано: $10.00 (на старт)
   ```

4. Введіть платіжні дані:
   - Кредитна/дебетова картка
   - PayPal (якщо доступно)

5. Підтвердіть оплату

6. Кредити з'являться через 1-2 хвилини

## Крок 5: Тестування ключа

### 5.1 Перевірка через веб-інтерфейс

1. Перейдіть в розділ **"Playground"** на OpenRouter
2. Виберіть модель (наприклад, Llama 3.1 8B Free)
3. Введіть тестове повідомлення: "Hello, who are you?"
4. Натисніть "Send"
5. Якщо отримали відповідь - ключ працює! ✅

### 5.2 Перевірка через ваш додаток

1. Запустіть VALORANT HUB:
   ```bash
   npm run dev
   ```

2. Відкрийте AI Chat

3. Натисніть ⚙️ Settings

4. Вставте ваш API ключ

5. Оберіть модель: **Llama 3.1 8B Free**

6. Натисніть **Save**

7. Напишіть тестове повідомлення: "Hello!"

8. Якщо AI відповів - все працює! ✅

## Крок 7: Моніторинг використання

### 7.1 Перегляд статистики

1. Перейдіть в **"Usage"** або **"Dashboard"**

2. Ви побачите:
   - Кількість запитів сьогодні/цього місяця
   - Використані токени
   - Витрачені кошти
   - Графіки активності

### 7.2 Розуміння токенів

**Що таке токен?**
- Токен ≈ 4 символи тексту
- Токен ≈ 0.75 слова
- "Hello, how are you?" ≈ 5 токенів

**Приклад розрахунку:**
```
Ваше питання: "Tell me about VALORANT" (5 токенів)
Відповідь AI: 200 токенів текста
Всього: 205 токенів = ~$0.0003 (для GPT-3.5)
```

### 7.3 Оптимізація витрат

💡 **Поради для економії:**

1. Використовуйте безкоштовні моделі коли можливо
2. Пишіть короткі, конкретні запити
3. Обмежуйте max_tokens в налаштуваннях
4. Кешуйте часті відповіді
5. Встановіть budget limits

## Крок 8: Безпека API ключа

### 8.1 Де НЕ зберігати ключ

❌ **НІКОЛИ НЕ РОБІТЬ:**
- Не комітьте ключ в Git
- Не публікуйте на GitHub/GitLab
- Не діліться в публічних чатах
- Не зберігайте в коді напряму
- Не надсилайте email

### 8.2 Де зберігати ключ

✅ **ПРАВИЛЬНІ СПОСОБИ:**
- У змінних оточення (.env файл)
- У менеджері паролів (1Password, LastPass)
- У секретах CI/CD (GitHub Secrets)
- У локальному localStorage (для фронтенду)
- У захищеному backend сервісі

### 8.3 Що робити якщо ключ скомпрометовано

1. **Негайно видаліть ключ:**
   - Зайдіть на openrouter.ai/keys
   - Знайдіть скомпрометований ключ
   - Натисніть "Delete" або "Revoke"

2. **Створіть новий ключ:**
   - Повторіть Крок 2
   - Використайте нову назву

3. **Оновіть додаток:**
   - Замініть старий ключ на новий
   - Перевірте всі місця де використовується

4. **Перевірте витрати:**
   - Подивіться usage за останні дні
   - Якщо є підозрілі запити - зверніться до support

## Крок 9: Часті помилки та рішення

### Помилка 401: Unauthorized

**Причина:** Невірний або прострочений API ключ

**Рішення:**
1. Перевірте що скопіювали ключ повністю
2. Переконайтесь що немає пробілів на початку/кінці
3. Створіть новий ключ якщо старий не працює

### Помилка 402: Payment Required

**Причина:** Недостатньо кредитів для платної моделі

**Рішення:**
1. Поповніть баланс (Крок 4)
2. АБО змініть на безкоштовну модель (Llama 3.1 8B Free)

### Помилка 429: Rate Limit Exceeded

**Причина:** Перевищено ліміт запитів

**Рішення:**
1. Зачекайте 1 хвилину
2. Збільште rate limit в налаштуваннях ключа
3. Оптимізуйте кількість запитів у додатку

### Помилка 500: Server Error

**Причина:** Проблема на стороні OpenRouter

**Рішення:**
1. Зачекайте кілька хвилин
2. Перевірте статус на openrouter.ai/status
3. Спробуйте іншу модель
