# 🚀 AI Chat - Швидкий Старт

## Як швидко почати користуватися AI чатом

### Крок 1️⃣: Отримайте API ключ (5 хвилин)

1. Відкрийте **[openrouter.ai](https://openrouter.ai)** в браузері
2. Натисніть **"Sign Up"** і зареєструйтесь (можна через GitHub/Google)
3. Після входу перейдіть в **"API Keys"**: [openrouter.ai/keys](https://openrouter.ai/keys)
4. Натисніть **"Create Key"**
5. Дайте назву ключу (наприклад: "Valorant HUB")
6. Натисніть **"Create"**
7. **ВАЖЛИВО**: Скопіюйте ключ одразу! Він показується тільки один раз

### Крок 2️⃣: Налаштуйте чат (1 хвилина)

1. Запустіть проект:
   ```bash
   npm run dev
   ```

2. Відкрийте в браузері: `http://localhost:5173`

3. На головній сторінці натисніть картку **"AI Chat Assistant"** 🤖

4. Натисніть іконку налаштувань ⚙️ у верхньому правому куті

5. Вставте скопійований API ключ

6. Оберіть модель (рекомендую **"Llama 3.1 8B Free"** - безкоштовна!)

7. Натисніть **"Save"**

### Крок 3️⃣: Починайте спілкуватися! 💬

Готово! Тепер можете писати питання AI боту.

**Приклади запитів:**
- "Які найкращі агенти для початківців?"
- "Дай стратегію для карти Bind"
- "Як покращити прицілювання?"
- "Tell me about VALORANT weapons"

## 🆘 Проблеми?

### Помилка: "Please configure your OpenRouter API key"
👉 Вставте API ключ в налаштуваннях (⚙️)

### Помилка: "OpenRouter API Error: 401"
👉 Невірний ключ. Створіть новий на openrouter.ai

### Помилка: "OpenRouter API Error: 402"
👉 Оберіть безкоштовну модель (Llama 3.1 8B Free)

## 🎯 Коротко про OpenRouter

**Що це?** Платформа для доступу до різних AI моделей через один API.

**Чому OpenRouter?**
- 🆓 Є безкоштовні моделі
- 🚀 Швидкий та надійний
- 🔄 Доступ до моделей від OpenAI, Google, Meta, Anthropic
- 📊 Детальна статистика використання

**Ціни:**
- Безкоштовні моделі: $0 (назавжди!)
- Платні моделі: від $0.0001 за 1000 токенів
